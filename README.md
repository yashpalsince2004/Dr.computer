# Dr. Computer

Official website for **Dr. Computer** — Laptop & Computer Repair Services by Yash Pal.

Live site: [drcomputer.yashpal.me](https://drcomputer.yashpal.me)

## Tech Stack

- **Framework**: [Astro v5](https://astro.build)
- **UI Components**: React 19 + Lucide Icons + Tailwind CSS v4
- **Hosting**: GitHub Pages via GitHub Actions

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
